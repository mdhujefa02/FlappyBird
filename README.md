# Flappy Bird Game

This repository contains a Java-based implementation of the classic Flappy Bird game. The game provides a simple but engaging experience where the player navigates a bird through pipes to earn points.

## Project Description

The Flappy Bird game requires players to control a bird and avoid obstacles by navigating between gaps in pipes. The game keeps track of the player's score and features an intuitive graphical interface.

## Features

- Engaging and challenging gameplay.
- Score tracking system.
- Animated bird and moving pipes.
- Simple key-based controls.

## How to Play

- Press the spacebar to make the bird fly upward.
- Avoid hitting the top, bottom, or pipes.
- Navigate through as many pipes as possible to increase your score.

## Class Overview

### 1. **App.class / App.java**
The main entry point of the game, handling game logic and rendering.

### 2. **FlappyBird.java**
Defines the main game mechanics, including bird movement and collision detection.

### 3. **Graphics Resources**
- **bottompipe.png**: Image asset for the bottom pipe.
- **flappybird.png**: Image asset for the bird.
- **flappybirdbg.png**: Background image.
- **toppipe.png**: Image asset for the top pipe.

## Setup and Usage

### Prerequisites

- Java Development Kit (JDK) 8 or higher
- A code editor (such as IntelliJ IDEA, Eclipse, or VSCode)
